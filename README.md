# OnkyoRS232
Controlling your Onkyo Hifi via RS232 port. This project is based on the ESP32 board and runs via Home Assistant. Main benefit over the the IR is the current state: 
- ON/OFF
- Volume
- Current Input
This helps greatly in running automation based on the receiver state.
Thisis currentlz tested with Onkyo Amplifier TX-SR706. Should however work with most Onkyo amplituner wtih RS232 port.
